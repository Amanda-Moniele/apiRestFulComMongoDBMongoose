# ApiRestFul Com NodeJs MongoDB e Mongoose

Api RestFul com MongoDB e Mongoose: Neste projeto, desenvolvi uma API RESTful utilizando Node.js, MongoDB e Mongoose, aplicando boas práticas na estruturação de rotas e manipulação de dados. Implementei as operações CRUD (Create, Read, Update e Delete) para gerenciamento de informações no banco de dados, realizando a integração entre a aplicação e o MongoDB por meio do Mongoose. Para validar o funcionamento da API, executei testes manuais utilizando o Postman, verificando o comportamento dos endpoints, os códigos de status HTTP, as respostas da aplicação e o tratamento de requisições válidas e inválidas. O projeto permitiu consolidar conhecimentos sobre desenvolvimento de APIs REST, modelagem de dados, persistência no banco de dados e testes de endpoints.
